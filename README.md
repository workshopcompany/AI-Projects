- **OpenFOAM Injection Automation** — Automation tool for OpenFOAM simulations and fluid flow analysis support. [Open app](https://openfoam-injection-automation.streamlit.app/) · [Source](https://github.com/workshopcompany/OpenFOAM-Injection-Automation)
- **IELTS Speaking Video Maker** — AI-powered video generation and learning assistant for IELTS speaking practice. [Open app](https://ielts-speaking-video-maker.streamlit.app/) · [Source](https://github.com/workshopcompany/IELTS-Speaking-Video-Maker)
- **OpenSource Match Program** — A matching and management program for open-source project collaboration. [Open app](https://opensource-match-program.streamlit.app/) · [Source](https://github.com/workshopcompany/Opensource-match-program)
